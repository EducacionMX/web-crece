# Agente Web CRECE

El agente operativo principal esta en:

`D:\1. Asistente\.agents\AGENTE_WEB_CRECE.md`

Usa ese archivo como punto de entrada para sesiones de mantenimiento, actualizacion y control de calidad del sitio web del CRECE.

Fuentes locales obligatorias para este agente:

1. `README_MANTENIMIENTO.md`
2. `Prompt.txt`
3. El HTML que se va a modificar
4. `styles.css` si el cambio afecta diseno o layout
5. `sitemap.xml` si se agrega, elimina o renombra una pagina

Actualiza el archivo principal en `.agents` cuando cambien reglas institucionales, convocatorias, formularios, telefonos, correos, estructura de menus o flujo de publicacion.
